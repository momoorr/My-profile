# T06 실제 검사 기록 (검사 후 채우기)
- [ ] 새 계획 저장·원본 그대로 재조회
- [ ] 계획 수정 전후 revision 보존 (최초 1건)
- [ ] 할 일 5개 이상 작성·검색/태그/우선순위 정렬
- [ ] 완료 ↔ 진행 중을 여러 번 전환해도 완료 수 중복 없음
- [ ] 실행 기록 3개 이상, 시작·끝·소요시간·멈춘 이유 기록
- [ ] 되돌아보기의 예상/실제/차이와 누락 수 비교
- [ ] 새로고침 후 서버 저장값 보존
- [ ] 시크릿 창의 공유 링크에서 공개 계획만 읽히고 수정 불가
- [ ] 별도 시크릿 창에서 다른 익명 사용자의 비공개 계획을 조회할 수 없음
- [ ] 공개 웹페이지/소스/제출 파일에 비밀번호·연락처·secret 키 없음
- [ ] 실제 Supabase DB 레코드 확인, 개발자도구 콘솔 0 오류

**아직 수행하지 않은 항목은 통과 표시하지 마세요.**
