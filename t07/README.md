# T07 플랜두씨 다이어리 2 — 인증 버전

T06 원본과 분리된 T07 웹앱입니다. 기존 `t06_` 데이터베이스 테이블을 그대로 사용하며, 자동 익명 로그인은 하지 않습니다.

## 설치
1. T07 폴더의 `config.js`에는 T06에서 이미 사용한 **프로젝트 URL과 `sb_publishable_` 키**만 넣습니다. `config.example.js`를 복사해 사용하세요. 비밀번호, service_role, sb_secret_ 키는 금지입니다.
2. 기존 `t06_` 테이블과 RLS를 보존합니다. 스키마를 재실행하거나 기존 사용자 및 owner_id를 변경하지 않습니다.
3. `py -m http.server 5507 --directory "C:\\Users\\사용자\\Downloads\\aleph_t07"`로 실행하고 `http://localhost:5507/`을 엽니다.
4. Supabase Authentication의 Email ENABLED와 Confirm email ON을 유지하고, 가입 후 실제 이메일 확인 링크를 클릭합니다.
5. 회원가입 → 이메일 확인 → 로그인 → 계획 작성·새로고침 → 로그아웃 → 로그인 재진입 검사를 진행합니다.

## 중요한 점
- 같은 호스트의 T06 익명 세션과 충돌하지 않도록 T07에 `storageKey: 'aleph-t07-auth-session'`을 사용했습니다.
- 기존 T06 익명 데이터는 T07 새 계정으로 자동 이전되지 않습니다.
- 로그인 화면만으로 소유권 보호가 되는 건 아닙니다. DB의 RLS가 필수입니다.
- 기존 T06의 공개 링크 동작과 T07 로그인 우선 규칙은 별개이며, T07은 로그인되지 않은 경우 모든 앱 내용을 숨깁니다.
- 새 계정의 로그인 및 데이터 저장은 아직 사용자 환경에서 검증 전입니다.
- T07 5일 실제 기록 검사는 서로 다른 실제 Asia/Seoul 날짜에 직접 수행해야 합니다.
