## 테스트 체크리스트

- [ ] 시크릿 창에서 결과물/소스 URL이 로그인 없이 열림
- [ ] 게임 시작 → 진행 30초 → 성공 또는 실패 → 다시 시작
- [ ] 신호 하나에 여러 번 눌러도 판정 한 번만 반영
- [ ] 게임 중 다른 버튼에 포커스 이동 후 신호 버튼으로 복귀; Enter·Space 작동
- [ ] 일시정지 중 시계·판정 고정, 재개 후 그대로 진행
- [ ] 1366×768, 1920×1080 가로 넘침 0, 조작 요소 정상 표시
- [ ] 10분 연속 플레이 뒤 Console 빨간 오류 0건
- [ ] 각 그룹 10판 기록 후 난이도 값 700ms → 450ms만 변경됨
- [ ] 20판 CSV 내보내기 및 평균 점수, 성공 판 수 비교
- [ ] 정상 기록이 새로고침 후 유지됨
- [ ] 초기화 전 확인 창 '취소'하면 기록 보존, '확인'하면 0판 복구 (CSV 백업 후 검사)
- [ ] 빈 저장소 시작 가능 (새 시크릿 창)
- [ ] 손상된 JSON 저장소 자동 복구 (새 시크릿 창)
- [ ] 효과음 끄면 현재 소리 중단, 켜면 다시 재생
- [ ] 움직임 줄이기 활성화, 페이지/CSV/소스의 개인정보 및 비밀정보 0건
