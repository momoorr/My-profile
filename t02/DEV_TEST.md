# SIGNAL 30 — 제작자 자동 브라우저 검사 기록

검사 환경: Linux Chromium 144 + Playwright, HTML/CSS/JS 인라인으로 로드한 로컬 미리보기. **GitHub Pages 공개 배포 및 사용자 실사용 검사를 대체하지 않습니다.** 시간을 빠르게 전진시킨 검사는 실제 10분 연속 사용으로 간주하지 않습니다.

| 검사 | 자동 검사 결과 |
|---|---|
| 1366×768 / 1920×1080 / 390×844 | 가로 넘침 없음, 앵커 링크 대상 정상 |
| 시작 시 대기 → 진행 | 정상 |
| 신호 하나 연속 2회 클릭 | 첫 1점만 반영 |
| 일시정지 후 5초 가상시간 경과 | 남은 시간 29.0초로 고정 |
| 30초 가상시간 경과 | 실패 판정 및 기록 1건 저장 |
| 시작 후 18회 Enter·Space | 18점, 종료 시 성공 판정 |
| 완료 후 다음 판 / 진행 중 다시 시작 | 0점부터 시작 |
| 기본 10판 기록 → 난이도 전환 → 조정 10판 기록 | 기록 10/10 + 10/10, 비교 화면 출력 |
| 빈 저장소 | 기록 0/10, 시작 가능 |
| 저장된 유효 기록 재로딩 | 기록 1/10 유지 |
| 손상 JSON | 기본 기록으로 자동 복구 후 시작 가능 |
| 실행 중 JavaScript pageerror | 검사 중 0건 |

남은 **실제 사용자 검사**: GitHub Pages 시크릿 창에서의 공개 접근, 10분 연속 실제 플레이, 20회 실제 플레이 기록·난이도에 대한 본인 판단, 재시작/포커스/효과음/초기화 실기기 검사, Console 빨간 오류, 개인정보 확인.
