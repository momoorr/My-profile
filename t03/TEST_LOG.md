## 5. 실제 수정한 결함(수정 전후)

자세한 동일 입력값 재현 기록: `REGRESSION.md`

- 원인: JSON 복원 시 템플릿의 이미지 데이터는 형식만 검사하고 실제 디코딩하지 않음
- 수정 전: JPEG 이미지가 손상된 JSON을 잘못 복원 성공 처리한 후, 해당 템플릿을 누르면 로드 실패(Fail)
- 조치: 가져오기를 확정하기 전 **모든 템플릿 내부 이미지 디코딩** 확인, 실패하면 기존 편집 상태 유지
- 수정 후: 동일한 손상 JSON이 즉시 거부되고 기존 작업 유지(Pass)
