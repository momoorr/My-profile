# T03 극단 입력 오류 수정 전후 재검사

검사 입력: 정상 형식의 JSON 백업에서 **저장 템플릿의 이미지 데이터만** 디코딩할 수 없는 JPEG 데이터(`data:image/jpeg;base64,YWJjZA==`)로 바꾸어 복원합니다.

- **수정 전 FAIL:** 정상 JSON을 복원했습니다. 템플릿 1개가 반영됐습니다.; 이후 템플릿 선택 시 `저장 이미지가 손상되어 기존 화면을 유지했습니다.`. 이미지 자체를 열어보지 않아 잘못된 파일이 통과하는 결함을 확인했습니다.
- **수정:** JSON을 편집기에 적용하기 전에 현재 편집 이미지뿐 아니라 **모든 템플릿 이미지도 디코딩**해 검증하고, 하나라도 손상되면 일괄 취소합니다.
- **수정 후 PASS:** JSON 불러오기 실패: 이미지를 열지 못했습니다. 기존 작업은 유지했습니다.; 초기 작업 유지.

테스트는 Chromium 로컬 인라인 실행이며 실제 배포 후 JSON 복원 테스트는 사용자가 다시 확인해야 합니다.
