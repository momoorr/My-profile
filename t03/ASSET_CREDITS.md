# T03 이미지 출처 및 공개 기준

## 자체 제작 예제 이미지

- `sample-images/sample_1_900x900.png`: 이 과제에서 Pillow 코드로 그린 기하학 도형 이미지 (화이트·차콜·하늘색)
- `sample-images/sample_2_900x1125.jpg`: 이 과제에서 Pillow 코드로 그린 원형 도형 이미지
- `sample-images/sample_3_900x1600.png`: 이 과제에서 Pillow 코드로 그린 선형 도형 이미지
- `example_square.png`, `example_portrait.png`, `example_story.png`: **한 장 스튜디오** 앱에서 기본 예제 배경과 문구로 내보낸 자체 제작 결과 이미지
- 앱 내부 `기하학` / `원형` / `선형` 예제 배경: HTML Canvas 명령으로 직접 그린 디자인

위 예제는 **ChatGPT가 보조한 코드로 이 과제용으로 제작**했고, 타인 사진·유료 저작물·외부 저작권 이미지는 사용하지 않았습니다. 결과물은 화면에 예제 이미지로 제공되는 파일이며, 사용자 제공 사진은 포함하지 않습니다.

## 사용자 업로드 이미지

사용자가 가져오는 PNG·JPEG는 해당 이미지에 대한 사용 권한을 사용자가 직접 확인해야 합니다. 저작권, 상표권, 인물 초상권을 확인하지 않은 외부 이미지는 결과물을 공개할 때 사용하지 마세요.

## 개인정보·비밀정보 처리

- 본 편집기는 브라우저 내에서 이미지 내용을 읽고 canvas에 출력합니다. 별도의 외부 이미지 업로드 API나 트래킹 코드가 없습니다.
- 사용자 사진을 브라우저에 로컬 저장하거나 **백업 JSON** 안에 인코딩해 보관할 수 있습니다. JSON을 공개 GitHub 저장소에 업로드하면 사진 내용까지 노출될 수 있으므로 **개인 사진이 들어간 백업 JSON은 공개 저장소에 올리지 마세요.**
- 샘플 데이터와 완성 이미지에는 이름, 연락처, 회사 내부정보, 토큰, 비밀번호 또는 숨겨진 EXIF를 의도적으로 포함하지 않았습니다.
