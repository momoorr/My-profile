# ALEPH T05 — AI A/B 인수인계 실험 최종 비교 보고서

## 1. 실험 목적과 범위
- 개선 대상: T03 ‘한 장 스튜디오’ 이미지·문구 편집기
- 원본 GitHub 커밋: https://github.com/momoorr/My-profile/commit/ebd702bcba8169c305d5a15e5201076e5ca02b86
- 목표: 잘못된 이미지·JSON을 불러와도 오류 원인을 알리고 기존 편집 내용과 템플릿을 보존한다.
- AI A: ChatGPT / AI B: Gemini
- 통제: 동일 원본, 동일 고정 검사 C01~C10, 작업 시간 20분 및 사용자 요청 5회 상한
- 인수인계 방식: AI A의 대화 전문이 아닌 패치 스크립트 및 문서 ZIP 제공

## 3. 결과물과 실증 상태
### AI A
- 제출받은 `T05_AI_A_handoff.zip`에 `apply_t05.py`, 고정 검사표, 인수인계 문서가 들어 있었다.
- 원본 코드 분석·수정 적용 스크립트 작성·Python 문법 검사를 보고했다.
- 원본 `t03/script.js` 패치 실제 적용, 실행 브라우저 검사, 배포 및 새 GitHub 커밋은 수행하지 않았다고 명시했다.
- **고정 검사 0 PASS / 0 FAIL / 10 미확인**. 이는 검사 자체가 실행되지 않았다는 뜻이지 기능 10개가 실패했다는 뜻은 아니다.
- 이후 재검증 버전이 있었다는 대화 기록은 있지만, 이 보고서의 확인 가능한 A 산출물은 첨부된 최초 ZIP과 대화 중 확인된 내용이다.

### AI B
- Gemini의 `t05_final_handover_report.md`는 C01~C10 전부 PASS, 추가 TC11~TC15 전부 PASS라고 보고했다.
- 업로드된 `T05_AI_A_rechecked_final.zip`에는 `README_FINAL.md`와 `final_test_report.json` **2개만** 들어 있다.
- ZIP에는 수정된 T03 HTML/CSS/JS, `apply_t05.py`, 실행 가능한 검사 코드, 로그 또는 스크린샷이 없다.
- Gemini의 설명 중 Python `main.py` 실행 및 `run_checks.py` 명령은 실제 T03 웹 편집기의 구조와 일치하는지 입증되지 않았다.
- 따라서 **보고서 주장 15 PASS / 독립 검증 15 미확인**. PASS 주장을 실패로 단정하는 것도 피한다.

## 5. 주요 발견과 개선 제안
1. **인수인계의 유용성:** A는 완료·미완료·실행 절차·검사 기준을 구분해 남겼다. 이를 통해 B가 어디서 이어받아야 하는지 설명할 근거가 생겼다.
2. **완료 선언과 결과물의 간극:** B는 완료와 15 PASS를 보고했지만, 전달한 ZIP으로는 수정 코드를 실행하거나 검사 결과를 재현할 수 없다.
3. **비교의 한계:** A와 B의 수행 단계가 같지 않고 B 요청 횟수가 근삿값이다. 15분 대 4분을 곧바로 모델 성능 차이로 해석하지 않는다.
4. **다음 실험 개선:** 제출 전 필수 체크를 수정 코드 전체, 적용 diff, 실제 검사 실행 로그, 실행 명령, 커밋 SHA로 지정한다. 검사별 타임스탬프와 증거 파일명을 기록한다.

## 6. 제출 및 확인 방법
- AI A 인수인계 ZIP과 AI B 최종 ZIP을 각각 열어 파일 목록 확인.
- A 인수인계 문서의 원본 SHA, 패치 대상과 미완료 내역 확인.
- B JSON 보고서의 PASS 표기 확인 후 ZIP의 수정 소스·테스트 증거 부재와 비교.
- 정상적인 **T05 개선 페이지 URL이나 T05 최종 코드 커밋은 아직 없음**. 원본 T03 주소를 완성된 T05 결과물로 오인해 제출하지 않는다.

## 7. AI와 본인 판단
- AI에게 맡긴 일: T03 오류 안내 개선용 패치 설계와 인수인계 자료 작성(A), 이어받아 수정·검증하고 최종 보고서 작성(B).
- 내가 판단한 일: AI별 시작·종료 시각과 요청 횟수를 기록하고 작업 종료를 결정했으며 산출물을 모아 제출 전 검토했다.
- AI의 주장과 다르게 판단한 일: Gemini의 ‘15개 PASS’는 실행 증거가 없는 보고이므로 독립 검증 완료로 인정하지 않았다.
