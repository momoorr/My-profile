# BR-B v2 제작 환경 검사 기록

**범위:** Chromium에서 HTML·CSS·JS 파일 내용을 메모리에 로드한 브라우저 검사. 실제 논문 데이터는 변경하지 않았습니다.
**환경 제한:** 이 실행 환경의 브라우저는 file URL과 localhost 탐색을 차단해, 파일 내용을 주입하는 방식으로 화면과 상호작용을 검사했습니다. 이를 사용자 PC의 더블클릭 실행이나 공개 사이트 검증으로 기록하지 않습니다.
**미수행:** GitHub 업로드, 공개 URL 접속, 실제 사용자·동료 평가, 사용자의 오해가 완전히 제거됐는지에 대한 사용성 실험.
