# MOA · 근거 기반 답변 점검기 (BR-B v2)

**연구:** 김윤아, T10 「근거 제한 프롬프트는 미확인 안내를 줄이는가?」(2026-11-05)

**한 문장:** 기업교육 운영자가 AI 답변 초안을 검토할 때, 공식 안내자료와 확인되지 않은 후속 안내 약속을 대조해 답변을 검토·수정하도록 돕는 보조 도구. 최종 발송 판단은 담당자가 합니다.

## 실행

1. 이 ZIP의 전체 파일을 **같은 폴더 구조로** 압축 해제한다.
2. `index.html`을 Chrome, Edge, Safari 등의 브라우저로 연다. 별도 설치·로그인·계정·API 키·인터넷은 필요 없다. 다만 원문 논문 링크는 기존 공개 BR-A 사이트로 이동하므로 인터넷이 필요하다.
3. `01 문의 선택`에서 사례를 고른다. `02 AI 답변 초안`에서 A/B 응답을 바꾸거나 문장을 직접 수정한다. `근거 점검하기`를 눌러 `03 검토 결과`와 수정 예시를 확인한다.

### 빠른 확인

- **Q11 / A:** 팀원 수 질문을 고르고 `A 일반` → 점검 → T10 원문 판정에서 근거 없는 후속 공지 약속을 표시하면 정상.
- **Q11 / B:** `B 근거 제한` → 점검 → B에서도 후속 안내 약속이 표시되면 정상. B를 완전한 답변으로 분류하지 않는 게 핵심.
- **Q02 / B:** `Q02 · 경계 사례` → `B 근거 제한` → 점검 → 기본 판정은 오류 아님, 넓은 해석에서는 오류로 바뀐다고 안내하면 정상.
- **잘못된 입력:** 답변을 전부 지우고 점검 → 앱이 멈추지 않고 입력 필요 메시지를 보여주면 정상.
- **직접 고치기:** `곧 팀원 수를 5명으로 안내하겠습니다.`라고 입력 후 점검 → 확정하지 않은 수치/후속 약속에 관한 주의 문구를 표시하고 사람 확인이 필요하다고 설명하면 정상.
- **판정 경계:** 아래쪽 `논문 결과`의 세 탭을 바꾸면 기본은 A 20개 중 3개·B 20개 중 2개, 넓은 해석은 각각 3개, 좁은 해석은 각각 1개로 표시됩니다. 탭에 맞게 설명과 A−B 차이도 1개(5%p) / 0개(0%p) / 0개(0%p)로 바뀌어야 합니다.

## v2에서 바로잡은 화면 설명

- 연구 수치는 바꾸지 않았습니다. 답변 원문과 AI 보조 판정 데이터 두 파일은 이전 버전과 바이트 단위로 같습니다.
- 비율보다 **20개 중 몇 개 답변인지**를 크게 표시합니다. 한 답변에 해당 안내가 여러 번 있어도 답변 1개로 집계합니다.
- 점 20개는 Q01~Q20의 답변에 하나씩 대응합니다. 색이 있는 점은 선택한 기준에서 근거 없는 안내로 판정한 답변입니다. 나머지 점을 정답·안전·정상으로 표시하지 않습니다.
- 퍼센트는 선택한 판정 범위의 관측 비율입니다. 앱 정확도·전체 답변 정확도·앞으로의 오류율이 아닙니다. 1/20=5%여도 나머지 95%가 모두 정답이라고 검증한 것은 아닙니다.
- 기본/넓은/좁은 탭은 동일한 40개 응답의 해석만 바꾸며 새로운 실험이 아닙니다. 넓은/좁은 해석은 논문에서 제시한 사후 민감도 분석입니다.
- 개별 원본 답변의 검토는 기본 판정을 유지하며, 다른 판정 기준에서 결과가 달라지는 경우 근거와 함께 표시합니다. 아래쪽 통계 탭만 바꿔도 개별 검토가 다른 기준으로 전환되는 것은 아닙니다.
- `TEST_REPORT.md`는 이 제작 환경에서 실시한 검사 기록입니다. 사용자 PC 실행·GitHub 배포·실제 동료 평가는 별도입니다.

## 연구와 실제 작동의 연결

- 논문의 **가상 공식 안내 F01~F10, 20개 질문, A/B 성공 응답 40개, AI 보조 의미 판정**을 그대로 정적 데이터에 포함했다 (`research-data.js`, 같은 데이터의 읽기용 `research-data.json`). 원자료 전체 로그를 공개하지 않는다.
- 수집된 원본 답변과 일치하면 논문에서 기록한 판정 및 설명을 보여준다. 원본 판정에 없던 사람 채점 결과를 추가하지 않는다.
- **사용자가 고친 답변은 별도 방식**으로 처리한다. 제한된 표현 규칙으로 잠재 위험을 표시할 뿐, 새 답변의 의미를 검증하거나 오류율을 추정하지 않는다.
- 답변 제안은 F01~F10 중 해당 사실과 미확인 항목만 조합한 **참고 문장**이다. 실제 운영 자료나 담당자 승인 없이 전송하면 안 된다.
- 논문 결과: 기본 오류 A 3/20, B 2/20; 넓은 판정 A 3/20, B 3/20; 좁은 판정 A 1/20, B 1/20. 결과의 한 문항 차이는 판정 경계에 민감하다. B가 안정적으로 우수하다고 결론내리지 않는다.

## 파일 구조

- `index.html` : 앱 화면, 로컬에서도 직접 열림
- `app.css` : 모바일·데스크톱 반응형 디자인
- `app.js` : 문의 선택, A/B 전환, 원본 검토, 편집문 경고, 제안 문장, 건수·판정 기준 설명 전환
- `research-data.js` : 오프라인 표시용 공개 가상 자료
- `research-data.json` : 사람이 비교하기 쉬운 연구 데이터 사본
- `CHANGELOG.md`, `TEST_REPORT.md` : 수정 범위와 제작 환경 검사 기록
- 논문 PDF 링크 : 기존 BR-A 사이트에 공개된 T10 논문으로 연결됨 (논문을 열 때만 인터넷 필요)

## 개인정보·보안

- 학습용 **가상** 문의와 공식 안내 자료만 포함한다. 실명·연락처 등 실제 고객 개인정보는 없다.
- 브라우저에서만 처리하고 `fetch`, 외부 API, 분석/추적, 회원가입, 토큰, 비밀번호를 사용하지 않는다.
- `localStorage`/쿠키에 입력 내용을 저장하지 않는다. 실제 개인정보를 입력하지 말 것.
- AI 모델을 실시간 호출하는 앱이 아니다. `AI 활용`은 앱 제작 과정의 코드·문구·QA 보조를 의미한다.
