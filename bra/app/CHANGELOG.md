# BR-B v2 · 논문 수치 오해 방지 수정

사용자가 기존 5% 표시를 성능 점수처럼 읽을 수 있다고 지적하여 화면을 수정했습니다.

## 변경한 것
1. 제목을 “공식 자료에 없는 안내가 얼마나 포함됐나요?”로 바꾸고, 앱 정확도·성능 점수가 아니라는 설명을 앞에 배치했습니다.
2. 짧은 막대 대신 “20개 중 N개”와 20개 점을 사용합니다. 두 조건에서 같은 색과 표시 규칙을 사용하며, 색이 없는 점을 성공·정답이라고 부르지 않습니다.
3. 현재 판정 범위, 조건별 분모, 퍼센트의 의미, 답변 단위 집계임을 명시했습니다.
4. 오른쪽 결론·건수 차이·퍼센트포인트 설명을 세 탭과 동기화했습니다. 기본 차이는 1개(5%p), 넓은/좁은 차이는 0개(0%p)입니다.
5. ‘판정 없음 ≠ 정답 보장’과 ‘같은 40개에서 기준만 변경’을 표시했습니다.
6. 화면 낭독기용 요약과 키보드 조작을 유지하고, 320~1920px 화면 너비를 점검했습니다.

## 변경하지 않은 것
- 논문의 질문 20개, 성공 응답 40개, F01~F10, 판정 및 수치
- 원본 답변 점검 방식, 편집 문장 패턴 탐지, 참고 수정 문장
- API·로그인·추적·외부 전송 없음
- BR-A 기존 대표작 연결 패치의 내용
