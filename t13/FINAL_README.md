## 3. 확인 방법 — 3단계

1. **과제 제출 위치:** 예시 선택 → 문의 등록 → 초안 저장 → 공식 자료 확인 체크 → 검토 승인 → 처리 완료. **기대 결과:** `공통 안내`, `과제 제출` 메뉴만 안내, 최종 `처리 완료` 표시.
2. **최종 프로젝트 방식:** 예시 등록 → 검토 메모 작성 → `추가 확인 요청`. **기대 결과:** `정보 확인 필요`, 미확인 일정·절차를 생성하지 않음, 자동 승인 불가.
3. **개인 출결 확인:** 예시 등록 → 검토 메모 작성 → `추가 확인 요청`. **기대 결과:** `담당자 확인 필요`, 개인 출결값 추정하지 않음, 승인 불가.

추가 점검: 빈 문의 제출 시 오류 안내, 공식 자료에 없는 마감일을 답변에 덧붙인 경우 승인 거부, 기존 승인된 답변을 수정하면 승인 해제.
