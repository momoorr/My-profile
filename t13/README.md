## 한 줄 소개

기업교육 운영 담당자가 **가상 문의를 접수·분류**하고, 공식 안내자료에 근거한 **답변 초안을 사람이 검토·승인한 후 처리 상태로 관리**하는 정적 웹앱 데모입니다.

- 이 데모의 **승인/처리 완료**는 브라우저에 남는 표시이며, 실제 답변 발송이 아닙니다.
- **생성형 AI 호출, 로그인/권한, 공동 DB, 이메일 전송, 개인정보·출결 조회 기능은 없습니다.**
- 시연용 규칙/가상 공식 자료를 사용하므로 실제 문의에 대한 정확한 자동 분류를 보장하지 않습니다.

## 실행 방법

1. ZIP을 압축 해제합니다. `t13/index.html`, `t13/style.css`, `t13/app.js` 세 파일을 같은 폴더에 둡니다.
2. `t13/index.html`을 더블클릭합니다. 설치·API 키·회원가입·서버가 필요하지 않습니다.
3. GitHub Pages에 올린 후에는 `https://momoorr.github.io/My-profile/t13/`에서 새 시크릿 창으로 접속해 확인합니다. **공개 배포된 v0.2에서는 상단 `DEMO 02`가 표시됩니다.**

## 2차 점검 3단계

1. **공식 근거가 있는 문의:** `과제 제출 위치` 예시를 선택하고 문의를 등록합니다. 오른쪽 아래 **답변 초안**을 확인해 간단히 수정하고 `① 초안 저장` → **공식 자료 확인 체크** → `② 검토 승인` → `③ 처리 완료`를 누릅니다. 최종 상태가 `처리 완료`여야 합니다. 초안을 수정한 경우 다시 저장·승인해야 합니다.
2. **아직 공식 안내가 없는 문의:** `최종 프로젝트 방식` 예시를 등록합니다. `정보 확인 필요`와 답변 보류가 보여야 하고, 검토 메모를 적어 **추가 확인 요청**을 누르면 상태가 `추가 확인 요청`으로 바뀌어야 합니다. 이 문의는 승인·완료할 수 없습니다.
3. **개인 확인이 필요한 문의:** `개인 출결 확인` 예시를 등록합니다. `담당자 확인 필요`와 답변 보류를 확인하고, 검토 메모를 적어 **추가 확인 요청**을 누릅니다. 새로고침 후 상태가 유지되며, `처리 상태` 필터로 확인할 수 있습니다.

### 추가 오류·안전 검사

- `과제는 교육 플랫폼의 과제 제출 메뉴에서 진행하세요. 마감은 12월 1일입니다.`처럼 공식 자료에 없는 마감일을 초안에 추가해 저장한 뒤 승인해 보세요. **근거 외 문구 경고가 뜨고 승인되지 않는 것**이 기대 결과입니다.
- 빈 문의는 `3자 이상 입력` 안내가 나오며 중단되지 않습니다.
- 저장하지 않고 다른 문의로 이동하면 변경을 버릴지 확인합니다.
- 완료한 초안을 다시 수정·저장하면 **기존 승인이 해제되고 `검토 중`**으로 돌아갑니다.
- `예시 데이터 초기화`는 이 브라우저의 T13 M2 시연 기록을 지우므로 신중히 사용하세요.

## 사용하는 가상 공식 자료

- **자료 01 · 제출 경로:** 과제는 교육 플랫폼의 '과제 제출' 메뉴에서 제출한다.
- **자료 02 · 진행 방식:** 최종 프로젝트의 세부 진행 방식은 아직 문서에 정리되지 않았다.

'팀원 수', '마감일', '발표 일정', '다음 공지 채널', '개인 출결 값' 등은 가상 자료에 없으므로 추정하지 않습니다.

## 작동 원리

- 규칙 기반 분류: `공통 안내`, `정보 확인 필요`, `담당자 확인 필요`, `개별 상담`.
- 문의는 최대 100건, 글자 수 280자, 답변 초안 600자, 검토 메모 300자로 제한됩니다.
- 처리 상태는 `접수` → `검토 중` → `승인됨` → `처리 완료`, 또는 `추가 확인 요청`입니다.
- 공통 안내가 아닌 문의는 답변 승인을 비활성화합니다. 공통 안내도 명백한 미확인 일정·추가 메뉴·외부 연락처가 있으면 승인할 수 없습니다.
- 공식 자료 확인 체크는 **사용자가 직접 확인했다는 시연용 표시**입니다. 자동 사실 검증이 아니며 실제 운영 승인 기록이나 감사 로그가 아닙니다.
- 승인 후 수정·저장은 승인을 해제합니다. 완료는 별도 명시적인 클릭이 필요합니다. 실제 메시지는 전송되지 않습니다.

## 로컬 데이터와 M1 이전

- 문의와 검토 상태는 **현재 브라우저의 localStorage**에 저장됩니다. 서버/공동 DB가 아닙니다.
- 같은 GitHub Pages 출처에서 실행할 경우 M1의 기존 문의(`moa-t13-demo-m1-v1`)가 남아 있고 M2 기록이 없으면 새 구조로 **한 번 읽어 와** `접수` 상태로 시작합니다. M1 기록을 삭제하지 않습니다.
- 처음 세 가지 예시로 확인하려면 `예시 데이터 초기화`를 사용하세요. 단, M2에서 추가한 시연 기록도 초기화됩니다.
- 브라우저·기기를 바꾸면 데이터가 공유되지 않습니다. 로컬 파일(`file://`)의 저장 지원은 브라우저 설정에 따라 달라질 수 있습니다.
