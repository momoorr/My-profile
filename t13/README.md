# T13 · MOA 운영 콘솔 — 중간 점검 1차 (M1)

## 한 줄 소개

기업교육 운영 담당자가 가상 문의를 접수하고 **공식 자료에 따라 분류**해, 바로 안내할 수 있는 질문과 담당자 확인이 필요한 질문을 구분하는 시연용 웹앱입니다.

## 실행

- 설치 없이 **`index.html` 더블클릭**으로 실행합니다. 인터넷 연결, 로그인, API 키가 필요하지 않습니다.
- GitHub Pages 공개 주소는 **배포 확인 후** 제출란에 기재합니다. 아직 배포 전이면 URL을 임의로 적지 않습니다.
- 소스는 `index.html`, `style.css`, `app.js` 세 파일입니다. 세 파일은 같은 폴더에 있어야 합니다.

## 1차 확인 방법 — 세 단계

1. `과제 제출 위치` 예시를 선택하고 **문의 등록하고 분류하기**를 클릭합니다. `공통 안내`와 `과제 제출` 메뉴가 있는 공식 자료 기반 초안이 보이면 통과입니다.
2. `최종 프로젝트 방식` 예시를 등록합니다. `정보 확인 필요`, **답변 보류**로 나타나고 날짜·진행방식을 지어내지 않으면 통과입니다.
3. `개인 출결 확인` 예시를 등록합니다. `담당자 확인 필요`가 나오고 출결 값을 추정하지 않으면 통과입니다.

### 추가 확인

- 문의 칸을 비우고 등록하면 안내 메시지가 표시되며 앱이 멈추지 않습니다.
- 목록에서 다른 문의를 고르면 해당 문의의 결과가 표시됩니다.
- 분류 필터를 바꿔 문의를 확인할 수 있습니다.
- 브라우저가 로컬 저장소를 허용하면 새로고침해도 입력 기록이 유지됩니다. `예시 데이터 초기화`로 복원합니다.
- 모든 데이터는 **이 브라우저 안(localStorage)**에만 저장됩니다. 실무 협업 DB가 아닙니다.

## 가상 공식 안내자료 (이번 1차의 전체 근거)

- **자료 01:** 과제는 교육 플랫폼의 '과제 제출' 메뉴에서 제출한다.
- **자료 02:** 최종 프로젝트의 세부 진행 방식은 아직 문서에 정리되지 않았다.

## 이번 버전 / 이후 단계

| 범위 | 상태 |
| --- | --- |
| 가상 문의 접수 · 목록 | 구현 |
| 규칙 기반 `공통 안내`, `정보 확인 필요`, `담당자 확인 필요`, `개별 상담` | 구현 |
| 출처를 표시한 초안 / 모르는 내용 답변 보류 | 구현 |
| 답변 직접 수정, 운영자 검토·승인 | **2차 계획** |
| 처리 완료/확인 요청 상태 | **2차 계획** |
| 실제 Gemini/AI 자동 생성, 메일 발송, 로그인, 여러 담당자 DB | 구현하지 않음 |

**정확성 주의:** 단어를 찾는 시연용 규칙이므로 임의의 실제 문의를 정확하게 이해하거나 분류한다고 보장하지 않습니다. 공식 자료에 없는 내용과 애매한 경우에는 확인 대상으로 둡니다. 이 버전은 실제 AI API 호출을 하지 않습니다.

## 개인정보·보안

- 가상 문의만 사용하고 실제 이름, 연락처, 출결 정보, 비밀번호, 토큰을 입력하지 마세요.
- 원본 연구 응답·개인 리추얼은 포함하지 않았습니다.
- 사용자가 입력한 시연 문장은 브라우저 로컬 저장소에 남을 수 있습니다. 공용 기기라면 `예시 데이터 초기화`를 사용하세요.
- 실제 교육 운영에는 권한, 감사 기록, 인증, 개인정보 처리 등 별도 설계가 필요합니다.

## T10 논문 / BR-B 앱과 차이

- T10 논문: 근거 없는 AI 안내를 관찰하고 판정 기준의 한계를 보고한 실험.
- BR-B: 논문에 사용된 문장·판정 결과를 체험하는 **연구 점검기**.
- T13: 문의 **접수 → 규칙 기반 분류 → 사람 검토 예정**의 운영 흐름을 보여 주는 **업무 시연 앱**.

## 버전 기록

- **M1 / 2026-11-05:** 3가지 예시, 문의 접수·목록, 규칙 분류, 출처/답변 보류, 유효성 검사, 필터, 브라우저 로컬 저장 구현.
- **M2 계획:** 운영자 답변 편집·검토 및 처리 상태 관리.

## 재현 환경

정적 HTML, CSS, JavaScript. 서버·패키지 설치·API 호출 없음. GitHub Pages 같은 정적 웹호스팅에 `t13/` 폴더를 올리거나 로컬 `index.html`을 열어 사용합니다.
