# T13 · MOA 운영 콘솔 — 중간 점검 1차 기능 검사

- 검사 대상: `index.html`, `style.css`, `app.js` (M1 / 2026-11-05)
- 검사 방식: Chromium에서 동일 HTML·CSS·JavaScript를 로드해 조작 검증. **검사 환경의 URL 이동이 제한되어 페이지를 코드 주입 방식으로 로드함.** GitHub Pages의 공개 URL 실사용 검사는 배포 후 별도로 진행해야 한다.
- 검사 결과: **20/20 항목 통과**

## 주요 통과 내용

1. 첫 화면에서 목적과 대상 명시.
2. 가상 문의 3건 초기 표시.
3. 과제 제출 위치 문의 → 공통 안내, 공식 자료 01에 근거한 답변 초안.
4. 최종 프로젝트 진행 문의 → 정보 확인 필요, 미확인 일정·절차 생성하지 않음.
5. 개인 출결 확인 문의 → 담당자 확인 필요, 개인 상태 추정하지 않음.
6. 빈 문의 입력 → 오류 메시지, 페이지 중단 없음.
7. 불분명한 마감 문의 → 정보 확인 필요.
8. 개별 상담 문의 → 개별 상담.
9. 분류 필터와 선택된 문의의 상세 표시.
10. 시연용 로컬 저장 상태를 새 페이지에 복원(테스트에서는 동일한 저장소 인터페이스의 모의 상태를 사용함).
11. `<img onerror>` 등 HTML 유사 입력을 텍스트로 표시하며 HTML을 실행하지 않음.
12. 예시 데이터 초기화 기능.
13. 375px 모바일 가로 넘침 없음, 기능 버튼 표시.
14. 테스트 중 JavaScript 실행 오류 0건, 외부 네트워크 요청 0건.

## 제약 및 수동 확인 필요

- 정적 코드와 모의 저장소 테스트 결과는 실제 GitHub Pages **접근성**, 시크릿 창 **무로그인 접속**을 증명하지 않는다. 배포 후 실제 주소를 검증해야 한다.
- 웹브라우저의 파일 URL에서 localStorage 지원 여부는 환경별로 다를 수 있다. 공개 호스팅 환경의 실제 새로고침 검사를 권장한다.
- 다양한 자유 입력을 정확하게 분류한다고 보증하지 않는다. 이 버전은 **명시된 규칙과 가상 자료만 사용하는 데모**다.
- 답변 수정·승인·처리 완료는 **중간 점검 2차 구현 계획**에 해당한다.

3. `개인 출결 확인` 선택 후 등록 → 담당자 확인 필요, 답변 보류.
