## 주요 확인 사항

1. 공통 안내 문의: 초안 저장 전 승인·완료 비활성화.
2. 명시적 근거 확인 체크 후 승인, 승인 후에만 처리 완료 가능.
3. 마감일 등 근거 없는 문구를 덧붙인 답변은 승인 거부.
4. 승인·완료된 초안을 수정한 뒤 다시 저장하면 기존 승인 해제.
5. 최종 프로젝트 방식: `정보 확인 필요`, 답변 보류, 추가 확인 요청.
6. 개인 출결 문의: `담당자 확인 필요`, 임의의 출결 값 생성 없음, 승인·완료 제한.
7. 검토 메모 및 승인/완료 상태의 새 문서 복원(모의 localStorage).
8. 분류·처리상태 필터, 가상 문의 등록, 빈 입력, 악성 HTML 유사 문자열의 텍스트 표시.
9. M1 저장된 문의의 M2 이전과 손상된 M2 저장값의 안전한 예시 재초기화.
10. 375px 모바일 가로 넘침 없음, 버튼 동작 확인.
