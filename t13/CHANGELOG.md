# T13 · MOA 운영 콘솔 변경 기록

## M2 / v0.2 — 2026-11-05 · 중간 점검 2차

**바뀐 점**

- M1 문의 접수·분류 화면은 유지했습니다.
- 운영자 검토 영역에 **답변 초안 편집과 저장**, **공식 자료 일치 확인 체크**, **검토 승인**, **처리 완료**, **추가 확인 요청**을 추가했습니다.
- 문의별 처리 상태를 목록에 표시하고 처리 상태 필터와 완료 건수 요약을 추가했습니다.
- 승인 이후 다시 수정·저장하면 승인이 해제되도록 했습니다.
- 공식 근거가 없는 문의는 자동 답변과 승인을 막고, 검토 메모를 남겨 확인을 요청할 수 있게 했습니다.
- 과제 제출 위치 답변에 근거 없는 일자·다른 메뉴·후속 안내 약속을 넣으면 승인 전 경고를 표시합니다. 이 규칙은 완전한 사실 검증이 아닙니다.
- M1과 같은 브라우저 출처에서 등록한 가상 문의는 M2 첫 실행 시 읽어오되 기존 M1 저장값을 지우지 않도록 했습니다.

**바꾼 이유**

- 계획 v1의 3번째 핵심 기능인 **담당자 검토·처리**가 M1에서 미완성이었기에, 초안이 자동으로 '완료'가 되지 않는 실제적인 업무 흐름을 구현하기 위해서입니다.
- T10 논문에서 근거 없는 안내 표현이 판정에 영향을 주었던 문제를 참고해, **공식 근거 부족 → 보류**, **사람이 확인한 답변만 시연용 승인**으로 이어지도록 했습니다.

**M2의 한계**

- 생성형 AI, 실제 자료 검색, 관리자 로그인·인증, 메시지 발송, 여러 담당자 공동 DB, 실제 출결 조회는 없습니다.
- '승인', '처리 완료'는 그 브라우저에 남는 시연 상태로, 실제 교육기관의 처리 완료 실적이 아닙니다.
- 사용자 확인, GitHub 공개 배포, 최종 플랫폼 제출은 별도로 해야 합니다.

## M1 / v0.1 — 2026-11-05 · 중간 점검 1차

- 가상 문의 3종, 접수·목록, 규칙 기반 분류, 답변 초안/보류, 입력 유효성 검사와 브라우저 로컬 저장 구현.
- 계획 v1을 처음 실행 가능한 앱으로 옮겼으며 목표 변경은 없었습니다.
