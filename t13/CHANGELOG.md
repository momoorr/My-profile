# MOA 운영 콘솔 변경 기록

## M1 — 2026-11-05 (중간 점검 1차)

- **기존:** T13 계획 v1만 작성한 상태. BR-B는 T10 논문의 기존 응답을 점검하는 연구용 도구.
- **이번 추가:** 문의 접수와 목록, 규칙 기반 분류, 공식 근거와 답변 초안/보류를 보여 주는 새 웹앱.
- **추가 이유:** 연구 결과를 반복하기보다는 기업교육 담당자가 **문의 접수 → 안내 근거 확인**의 업무 흐름을 사용해 볼 수 있도록 설계.
- **범위 조정:** 실제 생성형 AI, 개인 출결 조회, 답변 자동 발송은 제외. 운영자 답변 수정·승인·상태 관리 기능은 2차에서 구현할 예정.

변경된 목표가 아니라 계획 v1을 첫 구현물로 옮긴 단계임. 중간 점검 2차에 기능 추가 시 새 버전을 별도로 기록할 것.
