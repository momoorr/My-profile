03 / REVIEW

왜 이렇게 만들었을까요?

01

정보가 없으면 없다고

응답 실패 시 직전 정상값을 새로 조회한 것처럼 표시하지 않습니다. 현재 오류와 과거 정상 데이터는 서로 다른 칸에 표시됩니다.

02

비밀 없는 호출

로그인·인증·API 키 없이 호출합니다. 개인 위치, 이름, 연락처와 브라우저 위치 권한은 사용하지 않습니다.

03

실제 날짜만 기록

브라우저가 읽은 Asia/Seoul 날짜에 원천 시각을 검증한 뒤 한 건 저장합니다. 다른 실제 날짜는 다음 날 다시 조회해야 합니다.

검사와 영수증을 구분하는 이유

이 정보판에는 두 가지 서로 다른 모드가 있습니다. 실제 공개 API 모드는 서울의 현재 기온을 조회해 브라우저의 날짜별 기록을 저장합니다. 합성 테스트 모드는 공식 ALEPH T04 ZIP에서 검증한 9개 고정 응답으로 저장·오류·복구 계산을 시험합니다.

합성 테스트 모드의 2026-08-24와 2026-08-25는 가상 날짜로 실제 조회 증거가 아닙니다. 과제의 t04_day 봉인 영수증 2건은 사이트가 자동으로 만들어줄 수 없으며, ALEPH 플랫폼에서 발급·보존되는지 최종 점검이 필요합니다. 제출 화면에서 수동으로 발급한 것처럼 주장하지 않습니다.
