# T04 공식 자산 통합 및 실행 검사 기록

## 제작·자동 테스트에서 확인한 항목

| 검사 | 결과 | 근거 |
|---|---|---|
| 공식 ZIP의 asset-manifest.json 기반 원본 17개 길이·SHA-256 | 통과 | 17/17 일치, official-assets/에 보관 |
| 공식 NORMAL-D1-A(100) → D1-B(105) → D2(120) | 통과 | 1행 동일 ID로 갱신 → 2행, 변화 절댓값 15 |
| 공식 실패 5종 TIMEOUT/AUTH-401/RATE-429/OFFLINE/SCHEMA-BREAK | 통과 | 각 `stale / 해당 error_code`, 이전 값 105·1행 유지 |
| 공식 TIMEOUT → RECOVER-D2 | 통과 | `stale/timeout` → `fresh/none`, 2행·120·+15 |
| 공개값 모의 응답 기온 22.4°C 정규화·저장·화면 표시 | 통과 (모의 응답) | 데이터 형식 검증 및 원자료=정규화값=표시값 |
| 공개값 같은 날 재요청 중복 행 없음 | 통과 (모의 응답) | 1행 유지 |
| 1366×768, 1920×1080, 390×844 브라우저 너비 가로 넘침 | 통과 | Chromium 자동 검사 |
| 위 테스트 중 JS 예외 | 0건 | Chromium pageerror 감시 |

## 학생이 공개 배포 후 확인할 것

- [ ] GitHub Pages 배포 후 공개 URL이 새 시크릿 창에서 열림
- [ ] **실제** Open-Meteo 응답: 값·°C·제공처·원천 시각·조회 시각·Asia/Seoul 일치
- [ ] **실제** 원자료·브라우저 저장값·화면값 비교
- [ ] 실패 5종/복구를 공개 배포본에서 직접 눌러 확인
- [ ] 첫 번째 실제 KST 날짜 정상 기록 및 CSV 백업
- [ ] 두 번째 실제 KST 날짜 정상 기록 및 실제 어제 대비 계산 확인
- [ ] ALEPH 플랫폼 봉인 영수증 `t04_day` 정확히 두 건 생성 여부 확인
- [ ] 공개 심사 화면·소스·네트워크·Git·제출 자료의 비밀값/개인정보 0건 검사
- [ ] 실제 실측 출처 사용 조건과 저작권 표기 최종 확인

※ 합성 재생과 모의 API 응답은 실제 API 조회와 영수증 요건의 증거로 사용할 수 없음.
